🎯 Problem & Solution

The Business Challenge

💼 Canal 13 Financial Leak: MM$300 Annual Loss

Canal 13's Finance division identified a significant revenue leak: MM$300 annually lost due to expired content contracts (packaged material from external sources like films, series, and international programs) being inadvertently displayed after their licensing agreements expired.

Root Cause: Manual, disconnected processes across programming schedules, contract management, and accounting systems. No integrated visibility into contract expiry dates vs. actual air dates.

Key Pain Points

❌

Manual Schedule vs Contract Reconciliation

Programming team scheduled content, finance tracked separately. Misalignment common.

❌

No Real-Time Validation

Expired content discovered AFTER broadcast, resulting in expense disputes and accrual errors.

❌

Manual Reconciliation Overhead

Finance team spent 40+ hours monthly reconciling programming vs contracts vs GL.

🔧 Technology Stack & Architecture

Platform Components

Oracle Database | C++ Web Framework | Oracle ERP | QlikSense BI

System Modules

📅 Multi-Channel Scheduling Engine ▼

Technology: C++ web application with real-time validation

Capabilities:

  • Drag-and-drop schedule builder for all TV channels
  • Real-time contract validity checks (sub-second response)
  • Complex rule engine (blackout dates, syndication restrictions, channel exclusivity)
  • Multi-year forward planning with contract availability forecasts
📦 Content Registry & Inventory ▼

Technology: Oracle Database with metadata engine

Capabilities:

  • Centralized repository for 10,000+ packaged materials
  • External classification (IMDB) + internal rating systems
  • Contract metadata: expiry dates, exhibition counts, financial terms
  • Inventory projection: forecasts availability 6-12 months forward
💰 Financial & Accounting Module ▼

Technology: Oracle ERP integration (on-prem → Cloud migration)

Capabilities:

  • Automated expense recognition for exhibited content
  • Contract-to-GL reconciliation (nightly automated batch)
  • Tax compliance module (Chile requirements)
  • Audit trail on all financial transactions
📊 Business Intelligence Layer ▼

Technology: QlikSense connected to cube repositories

Dashboards & Analytics:

  • Finance Dashboard: contract utilization, variance analysis, loss recovery by channel
  • Programming Dashboard: channel fill rates, contract effectiveness, audience composition
  • Executive Dashboard: KPI tracking, trend analysis, forecasting
  • Real-time reporting eliminated 80% manual reconciliation
🔄 Data Migration Challenge (Largest Technical Achievement) ▼

Challenge: Transfer 10+ years of historical contract and programming data

Problem: Massive volume of manual, unstructured legacy data across disconnected systems

Solution Implemented:

  • Custom ETL routines to normalize and validate source data
  • Data quality checks at each transformation stage
  • Parallel run: old and new systems side-by-side during cutover
  • Manual reconciliation of top 100 vendor contracts pre-go-live
  • Post-cutover automated daily reconciliation (90-day validation period)
